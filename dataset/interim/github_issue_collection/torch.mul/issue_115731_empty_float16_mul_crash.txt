Description:

🐛 Describe the bug

torch.mul causes segmentation fault when multiplying a normal float16 tensor with an empty float16 tensor converted from a NumPy array.

Minimal reproducer:

import numpy as np
import torch

a = torch.tensor([2], dtype=torch.float16)

b = torch.tensor(np.array([], dtype='float16'))

print(torch.mul(a, b))

# print(torch.div(a, b))


Observed behavior:

The program crashes with segmentation fault:

python[2444066]: segfault at 0 ip 00007f8c393f8fa0 sp 00007fff645121c0 error 4 in libtorch_cpu.so


Expected behavior:

torch.mul should correctly handle multiplication involving empty tensors.

The operation should either:
- return a valid empty tensor result
- or raise an explicit runtime error

It should not crash the process.


Minimal Reproducer:

import numpy as np
import torch

a = torch.tensor([2], dtype=torch.float16)

b = torch.tensor(
    np.array([], dtype='float16')
)

result = torch.mul(a, b)
