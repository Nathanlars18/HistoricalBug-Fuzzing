Description:

When softmax is applied to an input tensor where all values are negative infinity,
the output contains NaN values.

The reason is that softmax internally performs exponential normalization.

For an input:

[-inf, -inf, -inf]

the computation becomes:

exp(-inf) = 0

and:

0 / (0 + 0 + 0)

which results in NaN.

This behavior can occur in transformer attention mechanisms where attention masks
remove all valid positions for a query.

The issue proposes a safer softmax behavior where fully masked rows return zeros
instead of NaN.


Trigger Condition:

Operation:
torch.softmax

Input condition:

All elements along the softmax dimension are:

-inf


Example:

Input:

tensor([
    -inf,
    -inf,
    -inf
])


Expected:

tensor([
    0,
    0,
    0
])


Observed:

tensor([
    nan,
    nan,
    nan
])


Minimal Reproduction:

```python
import torch

x = torch.tensor(
    [
        float("-inf"),
        float("-inf"),
        float("-inf")
    ]
)

y = torch.softmax(x, dim=0)

print(y)
print(torch.isnan(y))
Observed Behavior:
torch.softmax produces NaN values when the entire reduction dimension
contains -inf values.
Expected Behavior:
Softmax should return zero values for completely masked inputs instead of NaN.
