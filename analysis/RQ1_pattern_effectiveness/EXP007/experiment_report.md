# EXP007 Historical Bug Pattern Enhanced Harness Generation

## 1. Objective

This experiment evaluates whether historical PyTorch bug patterns can improve LLM-generated fuzzing harnesses.

Target research question:

Can historical bug knowledge enhance harness generation quality and fuzzing effectiveness?

---

## 2. Experimental Setup

| Item | Configuration |
|---|---|
| Framework | PyTorch |
| Version | 2.2 |
| Backend | CPU |
| API | torch.matmul |
| LLM | DeepSeek-V4-Pro |
| Fuzzer | libFuzzer |
| Time Budget | 300s |
| Environment | Docker ncsuswat/flashfuzz:torch2.2-fuzz |

---

## 3. Harness Generation

### Baseline

The baseline harness is generated using:

- API documentation
- Helper functions
- Harness template

without historical bug knowledge.

### Pattern-enhanced

The enhanced harness additionally receives:

- Historical bug pattern information
- Trigger condition extracted from PyTorch issue reports

The pattern is converted into an input generation strategy.

---

## 4. Harness Validation

Both harnesses successfully compiled in the same Docker environment.

| Harness | Compile |
|---|---|
| Baseline | Success |
| Pattern-enhanced | Success |

---

## 5. Fuzzing Results

| Metric | Baseline | Pattern |
|---|---:|---:|
| Executed Units | 43857 | 72384 |
| Exec/s | 145 | 240 |
| New Units | 299 | 397 |
| Final Corpus | 399 | 497 |
| Crash | 0 | 0 |

---

## 6. Analysis

The pattern-enhanced harness achieved higher fuzzing throughput and generated more corpus inputs under the same testing budget.

Compared with the baseline:

- Executed units increased by approximately 65%.
- Execution speed increased by approximately 65%.
- Final corpus size increased by approximately 25%.

These results indicate that historical bug patterns can guide LLM harness generation and improve exploration efficiency.

---

## 7. Limitation

This experiment only evaluates one API and one historical bug pattern.

Future experiments will extend to more PyTorch APIs and multiple bug pattern categories.

# EXP007 Historical Bug Pattern Enhanced Harness Generation

## 1. Experiment Objective

This experiment evaluates whether historical PyTorch bug patterns can improve LLM-generated fuzzing harnesses.

We compare:

- Baseline:
  LLM generated harness without historical bug knowledge.

- Pattern-enhanced:
  LLM generated harness with historical bug pattern injected into prompt.


## 2. Target API

API:

torch.matmul


Framework:

PyTorch C++ CPU backend


Environment:

- PyTorch 2.2
- LLVM libFuzzer
- DeepSeek-V4-Pro


## 3. Historical Bug Pattern

Selected bug pattern:

matmul_pattern_001


Pattern category:

Memory layout / alignment related corner case


Extracted constraints:

- float32 tensor
- unaligned memory layout
- offset based storage
- boundary memory condition


## 4. Harness Generation


### Baseline Harness

Prompt:

API documentation + helper skeleton


Generated strategy:

- Generate two tensors
- Execute torch::matmul
- Catch runtime exceptions


### Pattern Enhanced Harness

Prompt:

API documentation
+
historical bug pattern


Generated strategy:

- Generate tensors
- Apply unaligned memory transformation
- Explore offset variations
- Execute torch::matmul


## 5. Fuzzing Configuration

Time:

300 seconds

- value profile enabled
