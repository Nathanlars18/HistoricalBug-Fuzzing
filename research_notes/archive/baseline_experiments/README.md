# Early Baseline Experiment Archive

EXP001-EXP004 are retained as an early exploration and reproduction archive.
They document the progression from understanding FlashFuzz through baseline
reproduction, statistics calibration, and the first full baseline evaluation.

These experiments are not formal paper experiments. The formal experimental
line begins with EXP005, which provides the coverage baseline used by later
historical bug pattern experiments.

Only lightweight research notes and summary statistics are archived here. Raw
coverage output, complete run results, corpora, binaries, build products,
caches, helpers, and large logs remain excluded.
