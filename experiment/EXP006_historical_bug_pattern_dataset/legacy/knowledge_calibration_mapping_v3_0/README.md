# Knowledge mapping 3.0 calibration archive

This directory preserves the three Knowledge records generated with mapping
`3.0` and prompt `knowledge_extract_v3_0` during calibration on 2026-10-03.

They were moved here without semantic editing after mapping `3.1` introduced
clearer boundaries for non-required historical conditions, risk hypotheses,
and evidence-status labels. They are not active EXP006 Knowledge inputs and
must not be discovered by downstream EXP011 readers.

The original relative layout below `knowledge_base/v3/` is retained for audit.
